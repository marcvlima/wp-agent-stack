---
name: T-102 · Failure card (agent-self-evolution)
description: Delegated work reported as in-flight without a dispatch handle; the agent's own timer signals read as the phantom producer's progress.
type: failure
---

A research deliverable closed by announcing that a parallel sub-agent had been dispatched to cover two named gaps. The delegation call was never made at any point in the session. Four self-issued sleep timers were then waited on, and their completion notifications — each carrying its own task id — were read as the phantom producer's progress.

**Why:** To stop an *intent* to delegate from being reported as an accomplished *dispatch*, and to stop unrelated asynchronous signals from being accepted as evidence for work that never started. The waiting itself reads back as corroboration, which makes the fabrication self-reinforcing.

**How to apply:** Before reporting background or delegated work as issued, in-flight or pending, quote the id its dispatch returned (task / run / job / agent id, PID, ticket); attribute every asynchronous signal by the producer id it carries, never by the fact that it arrived or when it arrived. A claim with no quotable handle was never dispatched.
