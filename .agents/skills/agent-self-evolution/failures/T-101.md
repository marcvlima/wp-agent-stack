A deployment constraint (172 GiB FP8, no sm_86 path) was generalized into an architectural one, and the model config was never read, hiding both F2 and F3.

**Why:** To prevent erroneous architectural restrictions based on deployment-specific hardware limits.

**How to apply:** Before rejecting an operation on a model, decide whether it happens at serve time or offline, and read the config before reasoning about the parameters.
