# Layer — conclave / Doctor Code evidence intake

Open this layer when hosting a Doctor Code or conclave round.

## MUST

- Place the **complete** session corpus in the floor's sandbox (transcript,
  outbox, runtime, usage; sibling files that are part of the same corpus).
- Tell the room the **identity** of the corpus: paths, sha256, byte sizes,
  binary/runtime identity. That is not a reading.
- Every voice in the room reads the files **itself**. The host does not
  pre-digest.
- After the floor names searches: execute **exactly** those, return raw
  sourced findings, no conclusion. Then the floor rules.

## NEVER

- Hand the room a host timeline, a host-named defect class, or a marker
  digest as the first view of the session (category
  `host-selection-of-session-evidence`).
- Research alone and present a synthesis as the answer (category
  `conclave-decides-research-together`).
- Key a fix on the identity of the failing instance (model name, app name,
  one tool) instead of the decidable condition.

## Detector

A first-round ask from which the room could skip the files and still "know"
the story is host-selection. Fix the ask; do not proceed.
