# AI/ML Implementation Council roster — L0 (always in context)

One line per seat, ≤15 tokens. The Moderator (Chief AI Systems Architect) never
holds a seat. The founder ratifies every outcome.

## Science & model lifecycle

1. **llm-scientist** — model architectures, scaling laws, capability boundaries, base-gap truths
2. **training-lead** — full train, SFT, preference methods, adapters, schedules, stop criteria
3. **inference-systems** — serving stacks, batching, KV/quant, speculative decoding, parser traps
4. **mlops-platform** — registries, promotion gates, canary, drift, reproducible serve builds
5. **eval-alignment** — task/agentic evals, contamination, statistical validity, measurable gates
6. **data-engineer** — corpus design, dedup, leakage, synthetic risk, domain mix ratios
7. **applied-productization** — real-traffic failure modes, latency UX, cost per session

## Hardware, topology & engine knobs

8. **hardware-architect** — GPU/memory reality, interconnects, thermals, Apple Silicon budgets
9. **cluster-topology** — TP/PP/EP/DP, multi-node, NCCL, when parallelism is vanity
10. **engine-config** — concrete argv/env/YAML, silent no-ops, copy-pasteable serve commands
11. **spec-recipe** — packages decisions as executable recipes with acceptance probes

## Agentic code-assistant mastery

12. **agentic-harness-master** — harness-owned agent loop, stall detection, continuation policy
13. **autonomous-swe-master** — long-horizon autonomy, plan ledgers, self-verify, error recovery
14. **realtime-pair-master** — IDE assistants, weak-model robustness, forced tool_choice, apply reliability
15. **agent-reliability-evaluator** — inaction metrics, loop-completion evals, model-independence gates

## Optional specialists

16. **multimodal-vlm** — vision towers, image/video token cost, VLM engine matrices
17. **rl-preference** — RLHF/RLAIF pipelines beyond offline DPO
18. **ml-security** — training-data exfiltration, model-layer injection, secret leakage
19. **finops-ai** — $/1M tokens, spot markets, when external API wins
20. **kernel-engineer** — CUDA/Metal kernels, graph capture, proven kernel-bound only
